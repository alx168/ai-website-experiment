# Glossary

## Harness
The repository structure, rules, documentation, and future checks that help AI agents make reliable progress.

## Agent
An AI system making or proposing changes in the repository.

## Bootstrap phase
The current setup phase focused on core structure and documentation before substantial app code.

## Canonical source
A source that should be treated as authoritative for a specific part of the project.

## Execution plan
A written plan for a meaningful piece of work, stored in `docs/exec-plans/`.

## Significant change
A change large enough to affect project direction, structure, workflow, or future implementation.

## App scaffolding
The first minimal implementation of the website structure, likely using the default stack.

## Default stack
The current assumed technical direction: Next.js, TypeScript, and Tailwind CSS, unless a later decision changes it.
